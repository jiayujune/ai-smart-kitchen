Understanding the Problem

What can I cook with what I already have?

User Problem

  • People have ingredients at home but do not know what to cook.
  • Most recipe apps start from recipes, not pantry constraints.
  • Users need realistic options with missing items and substitutions.

Project Hypothesis

Combining ingredient similarity, nutrition signals, user preferences, and supervised ranking can produce more useful recipe recommendations than simple keyword search.

Project Goals

From pantry input to explainable recommendations

1

Recommend recipes from available ingredients.

2

Rank by similarity, missing items, nutrition, and preferences.

3

Compare multiple AI/ML models and show evaluation results.

Supervised Learning Setup

Query + recipe becomes a training example

Input

User pantry query + candidate recipe

egg tomato rice onion

Pseudo-label Rule

  • matched_count >= 2
  • missing_count <= 6
  • coverage_score >= 0.25
  • knn_score >= 0.10

This creates a supervised ML pipeline even without manually collected user ratings.

MLP Neural NetworkLower0.7874Likely underfitting or needs more tuning

The MLP has high precision but low recall, so it misses too many relevant recipes. More tuning or more data would likely improve it.

Critical Analysis

Best classifier is not always the best recommender

Hybrid Score Strength

Explicitly rewards practical cooking constraints, especially fewer missing ingredients and transparent score components.

Supervised ML Strength

Learns relevance probability from engineered features and compares traditional and neural-network models.

Classification F1 and user-facing ranking utility can disagree, so both evaluation views are important.

Conclusion

Limitations and future work

Limitations

  • Pseudo-labels instead of real user ratings
  • Limited evaluation query set
  • Rule-based dietary and allergy filtering
  • Simple neural network without extensive tuning

Future Work

  • Use clicks, likes, saves, and ignores as real labels
  • Add cross-validation and hyperparameter tuning
  • Evaluate NDCG@K or MAP@K
  • Deploy a hosted demo
